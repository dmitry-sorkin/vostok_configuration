# Пользовательские конфигурации

🇷🇺 Русский | [🇬🇧 English](README.en.md)

В этой папке располагаются пользовательские конфигурации электроники. Их публикуют и поддерживают (или не поддерживают) в актуальном состоянии сами пользователи. Иными словами, эти конфигурации могут не подходить к актуальной версии документации.

⚠️ Перед использованием любой из этих конфигураций, обязательно сверьте схему подключения в начале файла и из инструкций к принтеру. Если они не совпадают, то подключать компоненты надо так, как это описано в конфигурации. Использование конфигурации при неправильной схеме подключения может привести к выходу из строя компонентов электроники или даже пожару. Будьте внимательны.
