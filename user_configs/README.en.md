# User configurations

[🇷🇺 Русский](README.md) | 🇬🇧 English

This folder contains user electronics configurations. They are published and maintained (or not maintained) by their authors themselves. In other words, these configurations may not match the current version of the documentation.

⚠️ Before using any of these configurations, compare the wiring diagram at the top of the file with the one from the printer's manual. If they do not match, the components must be wired up as described in the configuration. Using a configuration with an incorrect wiring diagram can damage the electronics or even cause a fire. Be careful.
